The project

Where philosophy begins with the land

Indigenous Stories of Philosophy is a research website from the University of Alberta. It gathers a small number of stories and sets each one on a map, so a reader can move from a place to an account and back again.

How the site is organized

  1. 01

    A large map

    The home page is the atlas. The map fills the screen because the collection is geographic, and a reader should see the places before the prose.

  2. 02

    A short list

    The same stories are gathered on their own page for readers who would rather browse titles. With so few accounts, the list stays readable.

  3. 03

    A full account

    Each story page holds the researched text, the place, and the categories that describe it, with a locator map back to the atlas.

Themes, kept light

The site will hold about five to ten stories during this grant. An advanced search would imply a catalogue the project does not have, and it would compete with the map.

Themes sit above the map and the list instead. Choosing one highlights the stories that share it and leaves the others in view, so the whole collection stays understandable. If the set ever grows much larger, a fuller search can be added without throwing out this layout.

What a story record can carry

Place, locality, and setting are known kinds of metadata. Community, language, and any further categories are not fixed yet. The story page reserves those fields so they can appear as soon as the research team confirms them, and so they can join the themes on the map.

The place mark

Stories are marked with the project’s own symbol: a pale ring and a gold point, the same point used in the logo. It is drawn for this site, so a marker reads as part of the collection rather than as a generic map pin.
